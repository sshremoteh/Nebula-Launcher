ПОДДЕРЖКА СМАРТФОНОВ

Клиент адаптирован под различные диагонали, соотношения сторон (16:9, 18:9, 20:9) и аппаратные платформы.

⚙️

ПРОЦЕССОРЫ И ЧИПСЕТЫ

  • Qualcomm Snapdragon: 8 Gen 1/2/3, 888, 870, 7xx, 6xx (полная поддержка Adreno Vulkan).
  • MediaTek Dimensity: 9000+, 8000+, 7000+ (Mali GPU через Vulkan или OpenGL ES).
  • Google Tensor: G1, G2, G3, G4 (аппаратное ускорение).
  • Samsung Exynos: Xclipse / Mali GPU.
📐

ФОРМ-ФАКТОРЫ ЭКРАНА

  • Альбомный режим (Landscape): основной режим с двухпанельным дашбордом.
  • Портретный режим: вертикальная компоновка для раскладушек (напр. Fujitsu F-03L) и компактных экранов.
  • Планшеты и Fold-устройства: адаптивная сетка без растягивания кнопок.
  • Вырезы и челки: безопасные отступы краев экрана (Safe Insets).
🕹️

ТАЧ-УПРАВЛЕНИЕ

  • Джойстик: плавное перемещение с регулируемым радиусом и поддержкой спринта.
  • D-Pad: дискретные стрелки движения для точного платформинга.
  • Кастомизация: свободное изменение координат, масштаба и прозрачности всех кнопок.
  • Тактильный отклик: виброотдача при разрушении блоков и ударах.

ОСОБЕННОСТИ ДВИЖКА

Технические параметры реализации клиента.

НАТИВНЫЙ БИНАРНИК RUST

Код компилируется напрямую в ELF/SO для архитектуры arm64-v8a без JVM-интерпретации геймплея на экране.

VULKAN И GLES 3.0

Поддержка низкоуровневого API Vulkan для Adreno и Mali с автоматическим откатом на OpenGL ES при необходимости.

JAVA СЕТЕВЫЕ СЕРВЕРЫ

Реализация протокола 777: вход на серверы Minecraft Java Edition, поддержка LAN-миров и оффлайн-режима.

ПАКЕТЫ МОДОВ И ШЕЙДЕРОВ

Встроенная работа с нативными пакетами .hshader и модами контента .hmod через файловый интерфейс.

TARGET SDK 34

Совместимость с Android 14 и 15: честный полноэкранный режим без устаревших рамок letterbox.

УПРАВЛЕНИЕ МИРАМИ

Экспорт и импорт сохранений через системный Android Storage Access Framework без root-прав.
